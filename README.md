## 🔧 How to Use `requirements.txt`

### 1. Create a Virtual Environment (Recommended)

#### Windows
```bash
python -m venv venv
venv\Scripts\activate
```

#### macOS / Linux
```bash
python3 -m venv venv
source venv/bin/activate
```
### 2. Install Required Packages

Once the environment is activated, install all dependencies using:

```bash
pip install -r requirements.txt
```

This command reads the file and installs every library needed by the project.
